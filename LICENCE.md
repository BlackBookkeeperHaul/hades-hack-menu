## 🧩 About

**Hades Companion** is a curated list of Hades open-source tools:

- **Overlays** — on-screen helpers, layout notes, room radar, boon reference
- **Quality-of-Life Helpers** — build catalog, keepsake notes, config presets
- **Research Notes** — run layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Room Radar — visualize room layout and exits
- Boon Reference — browse boon tiers and duo pairings
- Run Notes — record and review escape attempts
- Speed Control — adjust playback for study

### Wallhack
- Build Catalog — browse weapon aspects and upgrades
- Keepsake Notes — organize keepsake loadouts
- Mirror Notes — track Mirror of Night upgrades

### Aimbot
- God Mode Notes — study encounters with conservative settings
- Heat Tracking — segment study across Pact conditions
- Input Buffer Notes — chain dash and attack sequences
